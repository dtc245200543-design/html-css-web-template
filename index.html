01 — Web Development

Web Technology

HTML là viết tắt của HyperText Markup Language, được sử dụng để xây dựng cấu trúc của trang web. HTML định nghĩa các thành phần như tiêu đề, đoạn văn, hình ảnh, liên kết và biểu mẫu.

Kết hợp HTML với CSS và JavaScript giúp tạo nên những trang web có giao diện đẹp mắt, linh hoạt và có khả năng tương tác với người dùng.

02 — Programming

C Programming

C là ngôn ngữ lập trình hướng thủ tục được phát triển bởi Dennis Ritchie. Ngôn ngữ này thường được sử dụng trong lập trình hệ thống, hệ điều hành và các chương trình yêu cầu hiệu năng cao.

Học C giúp bạn hiểu rõ hơn về biến, kiểu dữ liệu, vòng lặp, hàm, con trỏ và cách chương trình tương tác với bộ nhớ máy tính.

03 — Object Oriented

Java Programming

Java là ngôn ngữ lập trình phổ biến hỗ trợ lập trình hướng đối tượng. Mã Java thường được biên dịch thành bytecode và thực thi thông qua Java Virtual Machine (JVM).

Java được sử dụng để phát triển ứng dụng doanh nghiệp, ứng dụng Android, dịch vụ backend và nhiều hệ thống phần mềm khác.
